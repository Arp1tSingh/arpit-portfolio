# Arpit Singh — Portfolio Website

A responsive single-page portfolio made with HTML, CSS and vanilla JavaScript. It is designed to deploy directly to GitHub Pages without a build step or external dependencies.

## Before submitting

Update these placeholders in `index.html`:

- `your.email@example.com` — replace with your actual email address (appears in the mail link and copy-email button).
- `https://www.linkedin.com/in/your-linkedin/` — replace with your LinkedIn profile URL.
- The DeepGuard project description — add an accurate summary of the problem, your contribution and the technologies used.
- `Add your expected graduation year` — replace with the correct year.
- Review the About, Skills and Experience sections so every statement accurately reflects your background.

## Run locally

Open `index.html` in a browser. No package installation is needed.

## Deploy with GitHub Pages

1. Push this repository to GitHub using the `main` branch.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/(root)`, then click **Save**.
5. Wait for the Pages deployment to finish, then open the site URL shown on that page.

## Suggested three-commit sequence

```bash
git add index.html
git commit -m "Create portfolio page structure"

git add style.css
git commit -m "Add responsive portfolio styling"

git add script.js README.md
git commit -m "Add interactive features and project documentation"
```
